## 💡 INSIGHTS IMPORTANTES

1. **O mockup do dashboard É a fonte de verdade** para cores e estrutura
2. **Consistência absoluta** entre user e professional é OBRIGATÓRIA
3. **Sistema de badges coloridos** é fundamental para categorização
4. **Templates reutilizáveis** são core feature para profissionais
5. **Dark mode** é o tema principal, não opcional
6. **Tipografia dual** (Gogh para títulos, Resolve Sans para corpo) cria hierarquia clara
