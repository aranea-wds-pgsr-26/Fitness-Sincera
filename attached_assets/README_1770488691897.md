## 🚀 GUIA RÁPIDO PARA REPLIT

### Passo 1: Setup Inicial

1. **Crie novo projeto Next.js no Replit**
```bash
npx create-next-app@latest fitness-app --typescript --tailwind --app
cd fitness-app
```

2. **Inicialize shadcn/ui**
```bash
npx shadcn@latest init
```
Escolha:
- ✅ Default style
- ✅ Neutral base color
- ✅ Yes to CSS variables

3. **Copie o `globals.css`**
- Abra [DESIGN_SYSTEM_SPECIFICATION.md](./DESIGN_SYSTEM_SPECIFICATION.md)
- Vá para a seção "globals.css - Tokens Completos"
- Copie TODO o conteúdo
- Cole em `app/globals.css`

---

### Passo 2: Instalar Componentes Base

```bash
# Layout
npx shadcn@latest add button card badge sidebar

# Navigation
npx shadcn@latest add tabs dropdown-menu

# Forms
npx shadcn@latest add input select label form

# Data Display
npx shadcn@latest add progress avatar

# Feedback
npx shadcn@latest add toast

# Overlays
npx shadcn@latest add dialog popover tooltip

# Charts
npm install recharts
```

---

### Passo 3: Configurar Fontes

Em `app/layout.tsx`:
```typescript
import { Bebas_Neue, Inter } from 'next/font/google'

const headingFont = Bebas_Neue({
  weight: '400',
  subsets: ['latin'],
  variable: '--font-heading',
})

const bodyFont = Inter({
  subsets: ['latin'],
  variable: '--font-body',
})

export default function RootLayout({ children }) {
  return (
    <html lang="pt-BR" className="dark">
      <body className={`${headingFont.variable} ${bodyFont.variable} font-body`}>
        {children}
      </body>
    </html>
  )
}
```

---

### Passo 4: Configurar Tailwind

Em `tailwind.config.ts`, adicione as cores contextuais:

```typescript
module.exports = {
  theme: {
    extend: {
      colors: {
        personal: {
          DEFAULT: 'hsl(var(--personal))',
          foreground: 'hsl(var(--personal-foreground))',
          light: 'hsl(var(--personal-light))',
          dark: 'hsl(var(--personal-dark))',
        },
        nutrition: {
          DEFAULT: 'hsl(var(--nutrition))',
          foreground: 'hsl(var(--nutrition-foreground))',
          light: 'hsl(var(--nutrition-light))',
          dark: 'hsl(var(--nutrition-dark))',
        },
      },
      fontFamily: {
        heading: ['var(--font-heading)', 'sans-serif'],
        body: ['var(--font-body)', 'sans-serif'],
      },
    },
  },
}
```

## 🆘 TROUBLESHOOTING

### Cores não aparecem?
✅ Verifique se copiou o `globals.css` completo
✅ Verifique se adicionou as cores no `tailwind.config.ts`
✅ Reinicie o dev server

### Fontes não carregam?
✅ Verifique imports no `layout.tsx`
✅ Verifique se adicionou `fontFamily` no Tailwind config

### Componentes shadcn não funcionam?
✅ Execute `npx shadcn@latest init` primeiro
✅ Instale cada componente com `npx shadcn@latest add [nome]`
